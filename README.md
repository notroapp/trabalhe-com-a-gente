# Desafio Desenvolvedor Frontend - Victor Augusto

Olá, pessoal da Notro!

Aqui está a minha solução para o desafio de Desenvolvedor Frontend. Foi um projeto muito interessante e que me proporcionou uma ótima experiência de desenvolvimento. Dediquei bastante tempo e esforço para entregar uma aplicação que atende aos requisitos e é bem estruturada.

## Sobre o projeto

A aplicação foi construída em **React**, consumindo a API do GitHub para buscar e exibir repositórios com paginação. Além disso, implementei funcionalidades adicionais, como:

- Sistema de ordenação/classificação dos repositórios
- Favoritar repositórios, com armazenamento no **localStorage**, para fácil acesso posterior

## Tecnologias e bibliotecas utilizadas

- **React**: Optei pelo React pela sua eficiência na construção de SPAs (Single Page Applications) e experiência que proporciona ao usuário. Apesar de ter liberdade para escolher, React foi minha escolha principal, mas também consigo desenvolver usando Angular, caso necessário.
- **Vite**: Para criar e administrar o projeto React, por ser prático e eficiente.
- **Vitest**: Para testes unitários e integrados, graças à integração com o Vite.
- **Axios**: Para requisições HTTP à API do GitHub, pela sua facilidade de uso e segurança.
- **API do GitHub**: Já conhecida por mim, possibilitou atender ao desafio com dados reais.
- **React Router**: Para navegação entre páginas sem recarregar toda a aplicação, melhorando a experiência do usuário.
- **dotenv**: Para gerenciamento de variáveis de ambiente, aumentando a segurança.
- **ESLint**: Para manter a qualidade do código e evitar erros comuns.
- **LocalStorage**: Para salvar os repositórios favoritados localmente.

## Arquitetura e engenharia de software

- **Arquitetura MVC**: Usei essa arquitetura para manter a organização e separação de responsabilidades, além de ser uma exigência do desafio.
- **Testabilidade**: Priorizei a escrita de testes unitários e de integração para garantir qualidade e facilitar manutenção.

## Desafios enfrentados

Durante o desenvolvimento, enfrentei alguns desafios para melhorar a experiência do usuário, que resolvi com a ajuda do React Router e corrigindo bugs comuns no processo de desenvolvimento.

## Próximos passos e melhorias

Para aprimorar o projeto, recomendo implementar um sistema de filtro mais avançado, por exemplo:

- Filtragem por linguagem
- Número de estrelas
- Data de criação

Isso poderia ser feito adicionando dropdowns ou outros tipos de seletores que atualizariam as queries para a API do GitHub, permitindo resultados mais personalizados.
